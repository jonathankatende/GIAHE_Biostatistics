The “NA” Median Survival Mystery

When reviewing the summary of the overall survival model, you will notice that the output for the median survival time returns NA. This is a frequent occurrence in epidemiological studies and is important to understand:

  • Statistical Definition: The Median Survival Time is the exact time point when the survival probability (\(S(t)\)) drops to 0.5 (50%).

  • The Data Reality: In this heart failure cohort, the survival probability at the end of the follow-up period (Day 241) is approximately 0.576.

  • The Conclusion: Because the curve never reaches the 50% threshold, the median is “not reached”. This indicates that more than half of the study population was still alive or censored at the time the study concluded.

The Solution: Landmark Survival at 100 Days

To remain informative for clinical decision-making when the median is unavailable, we report survival at a specific landmark time point. As shown in Section 3 of your code, the survival probability at 100 days is 75% (\(95\% CI: 70\%-80\%\)). This provides a concrete measure of patient prognosis that can be used to calibrate AI models or inform public health interventions.

6. Cox Proportional Hazards Model

Code 
cox_mod <- coxph(
  surv_obj ~ age + serum_creatinine + ejection_fraction + serum_sodium,
  data = heart,
  x = TRUE,
  y = TRUE
)

cox_mod %>%
  tbl_regression(exponentiate = TRUE) %>%
  bold_p() %>%
  add_nevent()

Interpretation:

  • Age (HR = 1.05): Each additional year increases the hazard of death by 5%.
  • Serum creatinine (HR = 1.39): Higher kidney dysfunction strongly increases mortality risk.
  • Ejection fraction (HR = 0.96): Better cardiac function is protective.
  • Serum sodium: Not statistically significant in this model.

This highlights the importance of multi-organ interactions in heart failure, consistent with a One Health perspective.

8. Calibration (AI Perspective)

Code 
dd <- datadist(heart)
options(datadist = "dd")

cox_rms <- cph(
  Surv(time, DEATH_EVENT) ~ age + serum_creatinine + ejection_fraction,
  data = heart,
  x = TRUE,
  y = TRUE,
  surv = TRUE
)

cal <- calibrate(
  cox_rms,
  cmethod = "KM",
  method = "boot",
  u = 100,
  m = 50,
  B = 200
)
