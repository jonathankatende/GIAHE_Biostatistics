1. Introduction

1.1 Research Question

Does increasing environmental exposure (e.g., air pollution) increase disease risk?

We begin with a simple model, then progressively uncover hidden biases and complexity.

generate_complex_data <- function(n = 200, seed = 42){
  set.seed(seed)
  
  age <- round(runif(n, 20, 80))
  BMI <- round(rnorm(n, 25, 4), 1)
  comorbidity <- sample(c("High", "Low"), n, replace = TRUE)
  comorb_numeric <- ifelse(comorbidity == "High", 1, 0)
  
  # One Health exposure (PM2.5 air pollution)
  air_pollution_level <- round(5 + (0.15 * age) + (0.4 * BMI) + 
                         (4 * comorb_numeric) + rnorm(n, 0, 3), 1)
  
  # Health outcome
  disease_risk <- round(10 + (0.5 * air_pollution_level) +
                  (-0.2 * age) +
                  (-5 * comorb_numeric) +
                  rnorm(n, 0, 2), 1)
  
  data.frame(age, BMI, comorbidity, air_pollution_level, disease_risk)
}

data <- generate_complex_data()

data$comorbidity <- ifelse(data$comorbidity == "High", "Low", "High")

Age is moderately correlated with air pollution exposure (r = 0.54) and strongly associated with disease risk (r = -0.62), indicating a substantial confounding effect. Adjusting for age is therefore essential to obtain an unbiased estimate of the exposure–outcome relationship

4.2 Interpretation

Age influences both:

  • exposure (air pollution)

  • outcome (disease risk)

    This creates confounding bias

AI Perspective

Stepwise selection is a primitive machine learning approach.

Modern AI methods use:

  • Lasso (L1 regularization)
  • Ridge (L2 regularization)

These methods:

  • handle high-dimensional data
  • reduce overfitting
  • perform automatic feature selection

While step() chooses which variables to keep, the Lasso “overwrites” unnecessary variables to zero, which is much more efficient when you have 200 predictors instead of 4.

8. Interaction Effects

8.1 Motivation

Does pollution affect everyone equally?

Maybe not - it may depend on age.

8.2 Simulation with Interaction

View R Code 
generate_interaction_data <- function(n = 250, seed = 42){
  set.seed(seed)
  
  age <- round(runif(n, 20, 80))
  comorbidity <- sample(c("Low", "High"), n, replace = TRUE)
  comorb_numeric <- ifelse(comorbidity == "High", 1, 0)
  
  air_pollution_level <- 5 + (0.3 * age) + (4 * comorb_numeric) + rnorm(n, 0, 3)
  
  disease_risk <- 10 + (0.7 * air_pollution_level) +
                  (-0.1 * age) +
                  (-0.01 * air_pollution_level * age) +
                  (-5 * comorb_numeric) +
                  rnorm(n, 0, 2)
  
  data.frame(age, comorbidity, air_pollution_level, disease_risk)
}

data_inter <- generate_interaction_data()

data_inter$comorbidity <- ifelse(data_inter$comorbidity == "High", "Low", "High")
data_inter$comorbidity <- factor(data_inter$comorbidity, levels = c("Low", "High"))

10. Conclusion

We have shown that:

  • Simple models can be misleading
  • Confounding biases estimates
  • Multiple regression corrects bias
  • Interaction reveals population heterogeneity
  • AI methods extend these ideas to complex datasets

Final Takeaway

A good model is not the simplest one, but the one that reflects the true data-generating process.
